OAB – On Air Broadcast 1.2.3 – רדיו אינטרנטי משלך
================================

1. הפעלה
--------
לחיצה כפולה על start-oab.bat (או על קיצור הדרך "OAB Studio" בשולחן העבודה)
- בהפעלה הראשונה נוצר קיצור דרך "OAB Studio" עם הלוגו בשולחן העבודה ובתפריט התחל.
  אפשר ליצור אותו שוב בכל זמן עם install-oab.bat.
- נפתח חלון שחור = השרת. משאירים אותו פתוח כל זמן שהרדיו פועל.
- האולפן נפתח בדפדפן (Chrome או Edge) בכתובת http://127.0.0.1:8000/studio
- אם Windows שואל על חומת האש: לאשר "רשתות פרטיות".

2. הגדרה ראשונה (פעם אחת)
--------------------------
באולפן: Settings ← Options (או Ctrl+P, או ⚙ למעלה מימין):
- Music folder: התיקייה של השירים, למשל C:\Users\Aviad\Music
- Ads folder: תיקייה עם קבצי הפרסומות
- Jingles folder: תיקייה עם ג'ינגלים (נכנסים אוטומטית לקיר הג'ינגלים 5×5)
- AutoDJ: כשאף אחד לא משדר – הרדיו ממשיך לנגן לבד מתיקיית השירים, 24/7
- Save settings
הספרייה נשמרת – לא צריך לבחור תיקייה בכל פעם.

3. שידור מהמחשב
----------------
- A / B טוען שיר לדק, ‏+Q מוסיף לתור. Auto mix מעביר משיר לשיר במעבר רך.
- GO LIVE ← Play.
- מיקרופונים: MIC 1 (מקש רווח) ו-MIC 2 (‏Shift + רווח). כפתור LINK ביניהם = שניהם נפתחים ונסגרים יחד.
  DUCKER (הסליידר האפור) קובע בכמה המוזיקה יורדת כשמיקרופון פתוח.
- LINE IN: כניסה למקור צליל חיצוני (מיקסר, נגן). כפתור הפעלה + סליידר עוצמה.
- בהגדרות (⚙) ← INPUTS: בוחרים כניסה מכרטיס הקול לכל אחד – MIC 1, MIC 2, LINE IN.
- פרסומות: לכתוב דקות (למשל 15,45) ולהדליק Auto. או Insert now.
- REC שומר את השידור לתיקייה recordings.
- בזמן שידור חי AutoDJ זז הצידה אוטומטית, וחוזר כשמפסיקים.

4. האזנה
--------
- כשנכנסים לנגן מופיעה ספירה לאחור של 5 שניות, ואז השידור נשמע.
- בבית (אותו Wi-Fi): הכתובת שמופיעה בחלון השרת, למשל http://192.168.1.20:8000
- מכל מקום: באולפן "LISTEN FROM ANYWHERE" ← Create public link.
  נוצר קישור https חינמי (Cloudflare). בפעם הראשונה מורד קובץ של כ-30MB.
  מגבלות: עד כ-200 מאזינים בבת אחת, והקישור משתנה בכל הפעלה.
- כדי לקבל אפליקציה בטלפון: לפתוח את הקישור ב-Chrome ← תפריט ⋮ ← "הוספה למסך הבית".

5. שידור מהטלפון (אנדרואיד)
---------------------------
- באולפן: Create public link ← Copy phone studio link ← לשלוח לטלפון.
  (המיקרופון בטלפון עובד רק דרך קישור https)
- לפתוח ב-Chrome ← סיסמה ← Open. אפשר "הוספה למסך הבית" ואז זה נפתח כאפליקציה.
- + מוסיף שירים מהטלפון או מספריית הרדיו. MIC, ג'ינגלים, REC, Go live.
- מומלץ אוזניות, כדי שהמיקרופון לא יקלוט את המוזיקה מהרמקול.
- המסך נשאר דלוק בזמן שידור. אל תעבור לאפליקציה אחרת באמצע שידור.

6. יותר מ-200 מאזינים / קישור קבוע (פתיחת פורט)
------------------------------------------------
- בראוטר: Port Forwarding ← פורט 8000 (TCP) ← לכתובת המחשב (מופיעה בחלון השרת).
- כדאי לקבע למחשב כתובת קבועה ברשת (DHCP reservation בראוטר).
- הקישור למאזינים: http://הכתובת-החיצונית-שלך:8000
  (את הכתובת החיצונית רואים באתר כמו whatismyip.com)
- מספר המאזינים מוגבל רק במהירות ההעלאה: כל מאזין ≈ 0.13 מגה.
  לדוגמה: העלאה של 50 מגה ≈ עד כ-350 מאזינים.

7. (הוסר) נגני ספוטיפיי ויוטיוב לא נמצאים יותר באולפן. שירים מיוטיוב מוסיפים מלינק – ראו סעיף 14.

8. חיפוש בספרייה לפי יוטיוב/ספוטיפיי (לא חובה)
-------------------------------------

  ← Credentials ← Create API key ← להדביק בהגדרות.
- Spotify: developer.spotify.com/dashboard ← Create app ← להעתיק Client ID ו-Client Secret.
החיפוש מראה פרטי שיר ותמונה. השירים עצמם מתנגנים מהקבצים שלך.

12. האולפן 2.0 – עבודה כמו ב-RadioBOSS
---------------------------------------
פלייליסט (באמצע המסך)
- מוסיפים שירים: לחיצה כפולה בחיפוש/Explorer, גרירה, או "+ Add".
- שינוי מיקום שיר: ▲ ▼ בסוף השורה (מופיעים כשעומדים עליה), גרירה עם העכבר, Ctrl+↑ / Ctrl+↓,
  או קליק ימני ← Move (למעלה, למטה, לשיר הבא, לסוף).
- Play / Next / Stop וכו' בשורת הכפתורים. Enter = נגן את השורה המסומנת.
- לחיצה ימנית על שורה: נגן עכשיו, נגן הבא (תור), האזנה מקדימה, עריכה, סוג קובץ,
  Track editor, הקלטת קריינות אחרי השיר, הוספת "stop".
- כמה פלייליסטים בלשוניות. קליק ימני על לשונית: שינוי שם, מצב תור, ייצוא M3U.
- הכול נשמר אוטומטית.

מעברים בין שירים (Settings ← Crossfades & file types)
- לכל סוג קובץ (Music, Jingle, Commercial, Voice track, News...) – fade ונקודת מעבר.
- קובץ שייך לסוג לפי התיקייה שלו או לפי מילה בשם הקובץ.

Track editor (Playlist ← Track editor)
- Cue in (מאיפה מתחיל), Intro end (ספירה לאחור עד שמתחילים לשיר), Mix (מתי השיר הבא נכנס),
  Cue out (איפה נגמר), ו-Gain לשיר. לוחצים על סמן ואז על גל הקול.

Scheduler (לשונית Scheduler משמאל)
- "+ Event": שעה, חזרה כל X דקות, ימים, תאריכים.
- פעולות: ג'ינגל/שיר, שיר אקראי מתיקייה, פלייליסט, הפסקת פרסומות, הקראת שעה,
  הקראת מזג אוויר, הקראת טקסט, שידור מכתובת (ממסר), פקודה.
- מתי: אחרי השיר הנוכחי / מיד / לתור.

Playlist Generator Pro (Playlist ← Playlist Generator Pro)
- כללים: למשל 3 שירים מתיקיית Rock ואז ג'ינגל אחד – חוזר עד האורך שביקשת.
- לא חוזר על אותו אמן קרוב מדי ולא על שיר שהתנגן לאחרונה. אפשר לשמור תבניות.

Ads Scheduler (Tools ← Ads Scheduler)
- דקות ההפסקה (למשל 15,45), שעות, המתנה מקסימלית, ג'ינגל פתיחה/סגירה.
- קמפיינים: לקוח, קבצים, תאריכים, ימים, שעות, מקסימום השמעות ביום.
- בחלון Ads Scheduler: "Automatic breaks" = הפסקות אוטומטיות, "Break now" = הפסקה עכשיו (גם ב-Tools ← Ad break now).
- "Ads report" – כמה פעמים כל פרסומת שודרה, עם ייצוא CSV ללקוח.

Report Generator (Tools ← Report Generator)
- כל מה ששודר, לפי תאריכים וסוג, שירים ואמנים מובילים, ייצוא CSV.

קריינות בין שירים – Voice tracking (Playlist ← Record voice track)
- מקליטים עם MIC 1, שומעים את סוף השיר הקודם ותחילת הבא, והקריינות נכנסת ביניהם.

הקראות (Tools ← Text to speech / Announce the time / weather)
- משתמש בקולות של Windows. מגדירים קול, עיר וטקסט ב-Options ← Announcements.
- לקול בעברית צריך להתקין ב-Windows חבילת דיבור בעברית (Settings ← Time & language ← Speech).

FX (לשונית FX משמאל)
- AutoAmp (השוואת עוצמות), Gap killer (דילוג על שקט), אקולייזר 5 ערוצים, קומפרסור, לימיטר.

AUX (לשונית AUX מימין)
- שני נגנים נוספים: On air = נכנס לשידור. כבוי = רק ליציאת סאונד שבחרת (למשל אוזניות).

שלט רחוק מהטלפון
- בטלפון באותו Wi-Fi: http://כתובת-המחשב:8000/remote (צריך את סיסמת השידור).

גיבוי
- File ← Settings backup שומר הכול לקובץ. File ← Restore settings מחזיר.


13. איפה הלינק לשידור?
----------------------
- כפתור "🔗 Listen link" למעלה ליד GO LIVE. מספר המאזינים מופיע למעלה ("listening").
- לינק לאינטרנט (לכולם): לוחצים "Create internet link" – הלינק מופיע תוך כחצי דקה, ומעתיקים אותו.
  הלינק משתנה בכל הפעלה מחדש של השרת.
- לינק לרשת הביתית (Wi-Fi של הבית) – מופיע תמיד.
- התוכנה מתאימה את עצמה לכל גודל מסך, כך ששום חלק לא מוסתר.
- start-oab.bat פותח את האולפן כחלון נפרד בלי שורת כתובת, כדי שיהיה יותר מקום.

- המאזינים מתחברים תוך פחות משנייה, גם כשעוד לא התחלתם לשדר (הם שומעים שקט,
  והשידור נכנס מעצמו ברגע שלוחצים GO LIVE או כש-AutoDJ מנגן). אם החיבור נופל – הנגן מתחבר מחדש לבד.
- הלינק של הרשת הביתית עובד רק בטלפון שמחובר ל-Wi-Fi של הבית. בחבילת גלישה – רק הלינק לאינטרנט.


14. שיר מלינק של יוטיוב
-----------------------
- מעתיקים לינק של שיר ביוטיוב ולוחצים Ctrl+V בכל מקום באולפן – השיר נכנס לסוף הפלייליסט.
- או: כפתור יוטיוב בסרגל הכלים / "+ Add" / Playlist ← Add YouTube link – עד 5 לינקים בבת אחת
  (אפשר לבחור "מיד אחרי השיר שמתנגן"). אפשר גם להעתיק כמה לינקים יחד ולהדביק ב-Ctrl+V.
- או: מדביקים את הלינק בתיבת החיפוש ולוחצים "⬇ Add to playlist".
- בזמן ההורדה השורה מראה אחוזים, והשיר מתנגן כשההורדה מסתיימת.
- השיר נשמר בתיקיית המוזיקה בתוך תיקייה בשם YouTube ונשאר בספרייה.
- בפעם הראשונה התוכנה מורידה לבד את yt-dlp (כ-18MB) ואת Deno (כ-40MB) – יוטיוב דורש אותם מאז 2025.
  הם נשמרים בתיקיית Radio. אם יוטיוב משתנה – התוכנה מעדכנת את yt-dlp לבד.
- אם הורדה נכשלת: השורה מראה את סיבת השגיאה, ולחיצה כפולה עליה מנסה שוב.
  פירוט מלא נשמר בקובץ Radio\data\youtube-log.txt.
- אם תשים את ffmpeg.exe בתיקיית Radio, השירים יישמרו כ-MP3 (וגם AutoDJ ינגן אותם). בלי זה הם נשמרים כ-M4A.
- שימו לב: השמעת מוזיקה ברדיו דורשת רישיון שידור (אקו"ם/פדרציה), ותנאי יוטיוב אוסרים הורדה – האחריות על המשתמש.


15. מדי עוצמה
-------------
- פס LED סטריאו (L/R) לאורך כל הנגן: מה שיוצא לשידור. ירוק עד ‎-12 dB, כתום עד ‎-3, אדום מעל. CLIP = עיוות.
- מתחת לכל מיקרופון מד VU מחוגים עם זכוכית ומנורה: 0 VU = רמה טובה, אדום = חזק מדי. הנקודה האדומה = שיא חזק.
  המד נדלק (המנורה נדלקת) רק כשכפתור המיקרופון דולק.
- Settings ← Ducker & LINE IN settings: הגדרות DUCKER ו-LINE IN.
- מסגרת ירוקה מהבהבת סביב הנגן כשהוא מנגן.
- סגנון גל הקול (waveform): View ← Waveform style – 6 סגנונות לבחירה. הבחירה נשמרת.
- Auto mix (מעבר אוטומטי לשיר הבא): Playlist ← Auto mix. עוצמת הפלייליסט: לשונית FX.
- קיצורי מקלדת: Settings ← Hot keys. לוחצים על המקש של פעולה ואז על המקש החדש (אפשר עם Ctrl/Alt/Shift).
  Backspace מוחק קיצור, Reset מחזיר לברירת המחדל. הקיצורים נשמרים וגם נכללים בגיבוי.
- השיר הבא מופיע בתוך הנגן, ליד שעת ההתחלה והסיום, ומהבהב עד שמגיע תורו.


16. LINE IN = הסאונד של המחשב
-----------------------------
- ברירת המחדל: LINE IN = Computer sound – רק מה שמתנגן במחשב, בלי המיקרופון של המחשב.
  (אפשר לשנות ב-Settings ← Ducker & LINE IN settings ← SOURCE, או Options ← LINE IN source.)
- Settings ← LINE IN on. בחלון שנפתח בוחרים "Entire screen" (כל המסך) ומסמנים "Share system audio" (שתף אודיו מערכת).
- מעכשיו כל מה שמתנגן במחשב (יוטיוב, ספוטיפיי, נגן אחר) נכנס לשידור דרך LINE IN, והעוצמה ב-⚙.
- הסאונד של האולפן עצמו לא נכלל, כך שאין הד.
- לחיצה על LINE IN שוב, או "Stop sharing" בדפדפן, מפסיקה.


17. מי מאזין
------------
- בנגן בטלפון: כל מאזין חייב לכתוב שם לפני שהשידור מתחיל (הנגן זוכר את השם לפעם הבאה).
- באולפן: לחיצה על "N listening" למעלה מציגה את שמות המאזינים ואיך זמן כל אחד מאזין.
- השמות מוצגים רק באולפן (עם סיסמת השידור) – המאזינים לא רואים זה את זה.
- LINK, LINE IN והגדרות Ducker/LINE IN נמצאים עכשיו בתפריט Settings (וגם אפשר לתת להם מקש ב-Hot keys).


18. שיתוף בווטסאפ
-----------------
- "🔗 Listen link" ← "Share on WhatsApp": נפתח ווטסאפ עם הודעה מוכנה "מחכים לכם, האזינו לשידור:" + הקישור (…/listen).
- חכו שנייה-שתיים עד שהכרטיס עם התמונה מופיע בשורת ההקלדה, ורק אז שלחו.
- ווטסאפ מציג כרטיס גדול עם כפתור ירוק "מחכים לכם, האזינו לשידור" – לחיצה עליו פותחת את הנגן.
- (בווטסאפ רגיל הכתובת עצמה תמיד מופיעה גם כטקסט קטן – אי אפשר להסתיר אותה.)
- התמונה של הכרטיס: Radio\web\share.jpg (1200×630) – אפשר להחליף בתמונה משלכם באותו שם.


19. יציאות כרטיס הקול
---------------------
- Settings ← Sound card outputs & inputs.
- Main output: לאן האולפן משמיע (רמקולים). השידור למאזינים יוצא תמיד לשרת, לא משנה מה נבחר כאן.
- Prelisten output (PFL): יציאה נפרדת, למשל אוזניות, לשמיעת שיר לפני שהוא עולה לאוויר (🎧 בשורה או Alt+לחיצה).
- ▶ Test ליד כל יציאה משמיע צפצוף קצר כדי לוודא שבחרתם נכון.
- אם ברשימה מופיע רק Default – לוחצים Refresh device list ומאשרים פעם אחת את המיקרופון; אז הדפדפן מציג את כל השמות.
- העמודה הימנית מציגה רק בקשות שירים. קיר הג'ינגלים, Stats ו-AUX הוסרו.
  הקלטות השידור: Tools ← Recordings. הלינקים למאזינים: 🔗 Listen link.


20. קומפרסור למיקרופונים
-----------------------
- מתחת ל-MIC 1 ול-MIC 2: כפתור COMP (הדלקה/כיבוי) ומד GR – כמה dB הקומפרסור מנמיך כרגע (כל נורה = 2 dB).
- הגדרות לכל מיקרופון: Settings ← Microphone compressor (או לחיצה על מד ה-GR):
  Threshold, Ratio, Attack, Release, Knee, Make-up gain, Low cut. השינוי נשמע מיד ונשמר.
- כפתורי המיקרופון הם אייקונים עגולים (שמאל = MIC 1, ימין = MIC 2). דולק = ירוק מהבהב. ביניהם LINK (כחול כשמחוברים).


21. שעון צף
-----------
- לחיצה על השעון למעלה פותחת חלון שעון צף (לחיצה נוספת סוגרת).
- גוררים מהפס העליון כדי להזיז, ומהפינה הימנית התחתונה כדי להגדיל/להקטין בחופשיות.
- 5 סוגי תצוגה ברשימה שבחלון: Studio clock (טבעת LED של שניות כמו באולפני רדיו), Classic, Dark modern, Neon, Digital.
- המיקום, הגודל והסוג נשמרים.


22. נגן Prelisten
-----------------
- משמאל לכפתורי הנגן: נגן להאזנה מוקדמת ביציאת ה-Prelisten (אוזניות) – לא עולה לשידור.
- טוענים שיר: גוררים שיר מהחיפוש/Explorer/פלייליסט אל הנגן, או 🎧 בשורת השיר, או Alt+לחיצה.
- Play/Pause, Stop, פס מיקום (לחיצה/גרירה קופצת למקום בשיר), זמן, ועוצמה.
- כשמנגן: אייקון האוזניות של הנגן דולק בכתום, וגם אייקון האוזניות בשורת השיר בפלייליסט.


23. השם החדש: OAB – On Air Broadcast
-----------------------------------
- התוכנה נקראת מעכשיו OAB. הלוגו (ללא רקע) מופיע באולפן, בנגן בטלפון, באפליקציית השידור, בשלט הרחוק,
  באייקונים של הדפדפן ובכרטיס של ווטסאפ.
- מפעילים עם start-oab.bat. (start-oab.bat הישן ממשיך לעבוד.)
- אפשר לשנות את שם התיקייה Radio ל-OAB – כל ההגדרות נמצאות בתוך התיקייה ועוברות איתה.
- קובץ הלוגו: web\oab-logo.png (שקוף). הקלטות נשמרות בשם OAB-תאריך.mp3.

24. הודעה למאזינים
לחצן המעטפה עם החץ ליד GO LIVE פותח חלון לכתיבת הודעה. לוחצים Send (או Ctrl+Enter),
וכל מי שמאזין עכשיו באפליקציה רואה את ההודעה באמצע המסך. מי שנכנס בשתי הדקות הבאות יקבל אותה גם.

25. איכות שידור
Settings → Stream quality: בין 128 ל-320 kbps. ברירת המחדל 256 kbps.
בחלון ההודעה: כפתור Emoji (155 אימוג׳ים ב־9 קטגוריות, כולל רדיו ושדרן) ובחירת פונט מתוך 12 פונטים בעברית. הפונטים שמורים בתוכנה עצמה (web/fonts), כך שלא צריך אינטרנט כדי לטעון אותם.

26. כפתורים חמים (5 עיגולים)
מימין לכפתורי הנגן. קליק ימני: Load audio file. קליק: מתנגן מעל השיר, והשיר יורד לעוצמה שנקבעה ב־Settings → Hot buttons. המסגרת מתמלאת לפי זמן הקובץ. קליק נוסף עוצר.
עכשיו 8 כפתורים. השם מופיע רק במעבר עכבר. קיצורי מקשים: F1–F8 (אפשר לשנות ב־Settings → Hot keys).
28. עמודות
התוכנה עולה רק עם עמודת הפלייליסט. עמודת הספרייה (Explorer · Search · Scheduler · FX) ועמודת Requests נפתחות מתפריט View, ונסגרות עם ה־✕ הקטן שלהן.

29. מנורת "על האוויר" ב־USB
Settings → Studio light (USB): בוחרים סוג התקן, Connect… פעם אחת, והמנורה נדלקת כשמיקרופון דולק.
נתמכים: מודול ממסר USB (USB relay, HID), נורת blink(1), נורת Luxafor, או Arduino (הקוד בתיקייה tools).

30. מיקרופון בשני הצדדים + Ducker
Options → MIC 1 / MIC 2 channels: ברירת המחדל "Both sides – automatic" מזהה באיזה צד של הכרטיס הקול המיקרופון נמצא ומשמיע אותו בשני הצדדים.
ה־Ducker מוריד את הפלייליסט, ואם בוחרים גם את LINE IN, כל עוד מיקרופון דולק.

31. אוזניות
Options → Headphones / speakers hear: ברירת המחדל: הכל חוץ מהמיקרופונים, בלי עיכוב. את הקול שלך שומעים דרך Direct monitor של הכרטיס קול. אפשר לבחור גם "Everything including microphones" (עם עיכוב קטן).

32. LINE IN מלשונית בדפדפן (יוטיוב)
Options → LINE IN source → "A browser tab": לוחצים LINE IN ובוחרים את לשונית היוטיוב. הלשונית משתתקת אצלך, והשיר נשמע רק דרך OAB – כולל ה־Ducker – גם באוזניות וגם בשידור.

33. חלון Options ותפריטים
Options מחולק לקטגוריות בצד: General, Sound outputs, Microphones, LINE IN, Hot buttons, Studio light, Folders, Announcements, Online.
תפריט Broadcast חדש: GO LIVE, הודעה למאזינים, לינק, מאזינים, מיקרופונים ו־LINE IN.

34. תוכנה למחשב (OAB Studio.exe)
מתקינים עם OAB-Studio-Setup. ההגדרות נשמרות ב־%APPDATA%\OAB.
LINE IN מיוטיוב: Broadcast → YouTube window. חלון היוטיוב של OAB שקט במחשב ונשמע רק דרך OAB – כולל Ducker.

35. כל הסאונד של המחשב דרך OAB
צריך להתקין פעם אחת את VB-Audio Virtual Cable (חינם) ולהפעיל מחדש את המחשב.
Broadcast → All computer sound through OAB: כל עוד OAB פתוחה, כל הסאונד של המחשב נכנס ל־LINE IN, עובר Ducker ויוצא לאוזניות דרך OAB. בסגירה – Windows חוזר לרמקולים.

36. מראה אולפן (זכוכית)
ברירת המחדל: תמונת האולפן ברקע, הפלייליסט בחלון זכוכית מימין.
לוחצים על הטבעת סביב המיקרופון בתמונה כדי להדליק או לכבות אותו (נדלק בירוק). כשמשדרים, שלט ON AIR בתמונה זוהר.
כפתור LINK (שני המיקרופונים יחד) נמצא בסרגל הכלים ליד השעון. פותחים עמודת Library או Requests – כפתורי המיקרופון עוברים לפינה השמאלית העליונה.
התוכנה עובדת רק במראה האולפן.
החץ הקטן בקצה הימני של הסרגל העליון מסתיר אותו; החץ שנשאר למעלה באמצע מחזיר אותו.
לחיצה כפולה על שיר בפלייליסט – השיר מתנגן מיד בנגן.
במראה האולפן: התפריטים בסרגל העליון; הטבעת הירוקה של מיקרופון דלוק היא מד עוצמה (מתמלאת עם הקול). שלט OAB בתמונה מרצד כל כמה שניות.
REC: Broadcast → Record on / off. חזרה / ערבוב / עצירה אחרי השיר: תפריט Playlist → PLAY. האזנה מקדימה מופיעה בפס התחתון כשהיא פועלת.

37. ערוץ המיקרופון (EQ, Low cut, קומפרסור, Ducker)
קליק ימני על טבעת המיקרופון פותח את חלון הערוץ שלו.
EQ פרמטרי: גוררים את הנקודות בגרף (גלגלת = Q, לחיצה כפולה = איפוס), או מסובבים את הכפתורים (גרירה למעלה/למטה, Shift = עדין, לחיצה כפולה = ברירת מחדל).
Low cut: תדר ושיפוע 12 / 24 dB לאוקטבה.
קומפרסור: Threshold, Ratio, Knee, Attack, Release, Make-up, עם גרף ומד GR.
Ducker (משותף לשני המיקרופונים): כמה המוזיקה יורדת, מהירות ירידה וחזרה, והורדה גם של LINE IN.
AUTO DUCKER: המוזיקה יורדת רק כשמדברים במיקרופון פתוח (רגישות לקול = Voice sensitivity).
Save: שומר את כל ההגדרות כ־Preset עם שם. Presets: בחירה מהרשימה טוענת את הכול. Copy to MIC 2 מעתיק למיקרופון השני.
בפס התחתון: כפתור כחול = הודעה למאזינים; כפתור החזרה (Repeat playlist) ליד כפתורי הנגן. במסך הפתיחה האותיות OAB נדלקות משמאל לימין לפי הטעינה.
כפתור Stop after song בפס התחתון (כתום כשדלוק): אחרי כל שיר הפלייליסט עוצר, והשיר הבא מסומן ומחכה ל־Play. ההתקנה באנגלית.

כפתור Requests בסרגל העליון (ליד Help) מראה כמה בקשות שלחו המאזינים; לחיצה פותחת / סוגרת את חלון הבקשות.
