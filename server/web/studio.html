Options

General

Plays the music folder when nobody is live
STREAM QUALITY
Higher quality sounds better but uses more internet upload: each listener needs about the bitrate (320 kbps ≈ 2.4 MB per minute). If listeners on mobile data cut out, choose 192 kbps. A change applies at once, also while you are live.

Sound outputs

Main output = what you hear from the studio (the broadcast itself always goes to the stream). Prelisten = a separate output, e.g. headphones, to hear a song before it goes on air (🎧 or Alt+click).
Music, jingles, hot buttons and the ducker are heard as on air. Hear your own voice with no delay through the sound card: turn on its Direct monitor (a knob or switch on most USB sound cards and mixers). A computer always adds a little delay to a microphone, so voice through the computer sounds late.

Crossfades & file types

A track belongs to a file type when it is in the type's folder, or its title / artist / file name contains the identifier. Everything else is Music. Mix = seconds before the end when the next item starts. Trigger = start the next item when the level drops below this (Mix is then the minimum overlap). "Prev" overrides the previous track's mix (useful for jingles and ads).
